# Keru Releases

Ce dépôt public sert exclusivement à distribuer les versions compilées de Keru.

Le code source, les profils, les bases de données utilisateur, les captures, les diagnostics et les journaux personnels n’y sont pas publiés.

Consultez la dernière release pour télécharger l’installateur recommandé, la version portable, le guide testeur et les sommes SHA-256.
